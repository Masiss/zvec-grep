## Why NO-GO for E3-02B

The observed hybrid top-10 gain is real, but:
- only 8 unique anchors split across FTS/vector at K=10;
- container entities account for most observed evidence and overlap many
  anchors, so a post-hoc filter is not an ANN-equivalent ablation;
- index is only 60 MB, vector index 21.5 MB; rebuilding costs ~65 min CPU;
- no per-declaration vector cardinality is exposed;
- removing container/value vectors risks losing configuration/default and
  multi-hop evidence, while the saving hypothesis is unquantified.

Do not open a split-collection policy experiment from this evidence. If the
owner explicitly reopens it, the next bounded step is instrumentation:
1. expose vector cardinality and per-declaration-type counts;
2. add held-out config/default/multi-hop queries;
3. run post-hoc filtering only as a diagnostic, labeled non-ANN-equivalent;
4. preregister a split test with CPU/disk/query saving bounds and a no-regression
   gate.
