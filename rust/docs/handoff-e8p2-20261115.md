## 3. Device / write contract (important)

- **CPU is default and supports incremental writes/reuse.**
- **Vulkan/CUDA/Metal are explicit opt-in and rebuild-only for writes.**
  Incremental writes fail closed because driver/runtime vector compatibility is
  not proven at the required granularity. Query-only access remains available.
- **Legacy saved `auto` indexes are query-only.** Every incremental write fails
  closed; rebuild requires an explicit concrete device. Do not infer or relabel
  the legacy backend.
- Same-device no-op remains a true zero-work no-op. Cross-device no-op is
  rejected.
- Workspace relocation preserves the saved concrete device, clears
  machine-local cache paths, and rejects cross-device writes.
- Explicit accelerator unavailable => fail closed; no silent CPU fallback.
- Device identity is the declared execution backend, not a hardware UUID.

The E8-P1 report's same-device Vulkan incremental claim is superseded by the
E8-P2 erratum.
