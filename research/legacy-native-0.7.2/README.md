# Archived legacy native source

Source-only preservation from the retired V1 fork, based on native 0.7.2-era
commit `8f6d600`. These patches include locally modified third-party sources.
They are NOT applied to or qualified against the recovered 0.8.0 runtime.
Original binary, source bundles, generated results and failure receipts are
preserved privately; no automatic build/install/benchmark is authorized here.
Do not mix the installed W4 library with recovered V2 tests or packages.
